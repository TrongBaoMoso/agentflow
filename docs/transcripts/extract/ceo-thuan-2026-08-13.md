### Strength markers used for directives

Vietnamese carries the force of a request in specific words, so strength is assigned on linguistic evidence, not tone:

| Marker in the quote | Reading | Assigned strength |
|---|---|---|
| `phải`, `cần`, `không được`, `bỏ`, `đừng có` | must / need / not allowed / remove / don't | `HARD` |
| `anh muốn`, `anh yêu cầu` | I want / I require | `HARD` |
| `nên`, `anh khuyên`, `anh đề nghị` | should / I advise / I propose | `HARD` when repeated or unopposed; otherwise `PREFERENCE` |
| `có thể`, `chắc`, `hình như`, `thử`, `tùy em` | can / probably / seems / try / up to you | `PREFERENCE` |
| interrogatives without a following instruction | — | `QUESTION` |
| `để anh làm việc với...`, `sau này mới build` | leave it to me / build later | `DEFERRED` |
